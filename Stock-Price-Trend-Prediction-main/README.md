# Stock Trend Prediction using FinBERT & Hybrid Ensemble Learning

This project implements a robust Machine Learning pipeline to predict the next-day opening price movement (Up/Down) of major tech stocks (AAPL, AMZN, MSFT, NFLX).

It leverages a **Hybrid Model** approach by combining state-of-the-art **NLP Sentiment Analysis** (using FinBERT) with traditional **Technical Indicators** (Price & Volume). To achieve high reliability and accuracy, it utilizes a **Soft-Voting Ensemble** of five distinct classifiers.

## 🚀 Key Features

* **Advanced Sentiment Engine:** Utilizes **FinBERT** (a BERT model fine-tuned on financial text) rather than simple lexicon-based tools like VADER. This allows the model to understand nuanced financial context from tweets and news headlines.
* **Hybrid Feature Set:** Merges social sentiment signals (`Tweet_Sentiment`, `News_Sentiment`) with hard market data (`Open`, `Close`, `Volume`) for a holistic predictive view.
* **Smart Preprocessing:**
    * **Text Cleaning:** Automatically strips URLs and Twitter handles to reduce noise.
    * **Holiday/Weekend Logic:** Uses Business Day (`resample('B')`) aggregation to correctly accumulate sentiment from Friday nights and weekends and apply it to the next trading Monday.
    * **Time Alignment:** Aligns all diverse data sources to a precise 24-hour trading window (9:30 AM to 9:30 AM).
* **Ensemble Strategy:** Employs a **Soft Voting** mechanism that averages the probability confidence scores of 5 diverse models (Random Forest, SVM, Logistic Regression, KNN, and a Multi-Layer Perceptron).
* **Rich Reporting:** Automatically generates detailed Excel reports (Accuracy, AUC-ROC, Precision, Recall) and day-by-day prediction logs.

## ⚡ Usage Pipeline

Run the three scripts in order to build and test the model.

### Step 1: Preprocessing (`preprocess.py`)
This script downloads the pre-trained FinBERT model, cleans the raw text, generates sentiment scores, handles the weekend/holiday time lag, and merges it with stock technical data.

```bash
    python preprocess.py
```
* **Input:** Raw CSV files from `Twitter/`, `News/`, and `Stock/`.
* **Output:** Saves hybrid datasets to `Processed_Data/`.
* *Warning:* This step is computationally intensive. Processing lakhs of tweets may take time (hours on CPU, minutes on GPU).

### Step 2: Model Training (`train.py`)
This script acts as a "Model Factory." It reads the processed data and trains five specific models for each of the four stocks.

```bash
    python train.py
```
* **Models Trained:**
    1.  Random Forest (RF)
    2.  Support Vector Machine (SVM) - *Probability Enabled*
    3.  Logistic Regression (LR)
    4.  K-Nearest Neighbors (KNN)
    5.  Multi-Layer Perceptron (MLP) - *2-Layer Neural Network*
* **Output:** Saves 20 trained model files to the `Models/` folder.

### Step 3: Evaluation & Ensembling (`evaluate.py`)
The final step acts as the judge. It loads the trained models, performs Soft Voting Ensembling, calculates metrics, and generates visualizations.

```bash
    python evaluate.py
```
* **Output:** All results are saved in the ```Results/ ``` folder.

## 📊 Outputs & Reporting

After running `evaluate.py`, check the `Results/` folder for the following files:

1.  **`Final_Model_Evaluation.xlsx`**: The master report. It compares the performance of every individual model against the Ensemble for every stock. Columns include:
    * Accuracy
    * AUC Score
    * Precision
    * Recall
    * F1-Score
2.  **`Predicted_Values.xlsx`**: A complete log of the test set predictions. This is crucial for auditing the model's daily behavior.
    * `Date`: The trading day.
    * `Actual_Move`: Did the stock go Up (1) or Down (0)?
    * `Predicted_Move`: What did the Ensemble predict?
    * `Ensemble_Confidence`: How sure was the model? (Probability score).
3.  **Visualizations (.png)**:
    * **ROC Curve Comparison:** A graph overlaying the skill of all 5 models + the Ensemble.
    * **Confusion Matrices:** Heatmaps showing True Positives, False Negatives, etc.
4.  **Text Reports (.txt)**: Quick-view summaries of model performance.

## 🧠 Methodology Details

### 1. Sentiment Analysis (FinBERT)
We utilize `ProsusAI/finbert`, a BERT model fine-tuned specifically on financial data.
* **Logic:** `Score = Probability(Positive) - Probability(Negative)`
* **Result:** A continuous, nuanced score between -1.0 and +1.0 for every single text.

### 2. Time Aggregation & Holiday Effect
* **Window:** Data is grouped from 9:30 AM ($t-1$) to 9:30 AM ($t$) to predict the market Open at $t$.
* **Holiday Fix:** We use `resample('B')` (Business Day). This ensures sentiment from Friday afternoon, Saturday, and Sunday is summed up and applied to **Monday's** prediction row, correctly capturing "pent-up" market sentiment.

### 3. Soft Voting Ensemble
Instead of a simple majority vote (Hard Voting), we use Soft Voting to maximize information gain:
1.  We get the **probability** of an "UP" move from all 5 models.
2.  We calculate the **average probability**.
3.  **Threshold:** If `Avg_Probability > 0.5`, Prediction = 1 (UP), else 0 (DOWN).
